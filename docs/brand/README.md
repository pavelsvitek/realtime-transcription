## Provenance

Extracted style snapshots from [ricocc/brands-design-md](https://github.com/ricocc/brands-design-md). Each `DESIGN.md` is a third-party reference, not an official brand kit from that company. The live source website listed in the file remains authoritative — compare major implementation decisions against it.
